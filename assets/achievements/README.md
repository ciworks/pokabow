# Achievement artwork

Original editable SVG artwork created for the Modern Tabletop achievement browser on 2026-10-18. No external stock art or font dependency. Shared colours follow docs/DESIGN_SYSTEM.md; rank glyphs are vector paths. Tiles are square.

- first_hand.svg: A-spade tile
- straight.svg: J/Q/K/A tile sequence
- full_house.svg: three queens and two kings
- edge_cluster.svg: four connected coloured tiles
- ai_victory.svg: honey trophy
- two_pair_10.svg: paired ranks and a ten-hand milestone
- perfect_match.svg: five-tile full house with matched edge band and check
- milestone.svg: fallback star for future catalogue IDs
- search.svg: interface search icon

The artwork is illustrative. Unlock conditions and descriptions come from the API, not from the icon. Add custom art mappings when new achievement IDs are introduced; unfamiliar IDs remain browseable with the fallback star.
