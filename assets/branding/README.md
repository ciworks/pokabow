# Pokabow branding

The current game name is **Pokabow**. Uppercase artwork uses **POKABOW**
(P O K A B O W). See the naming decision in `docs/GAME_SPEC.md` section 1.

## Current assets

- [Header logo v2](pokabow-header-logo-v2.png): current straight wordmark without
  a tile, with gold lettering and royal-blue outline; transparent PNG.
- [V2 design notes and generation prompt](pokabow-header-logo-v2.md).

## Earlier header variant

- [Header logo v1](pokabow-header-logo-v1.png): compact gold-and-blue wordmark
  with a colored-edge spade tile; transparent PNG.
- [Header design brief and generation prompt](pokabow-header-logo-v1.md).

## Archived concepts

The earlier full-size concept is preserved under its original filename and is
documented in [the superseded brief](polkabow-logo-concept-v1.md). It contains
the former spelling and is not current branding. Its revised full-size brief
uses the new name, but a replacement full-size image has not been generated.

Header logo v2 is integrated into `scenes/game/game_screen.tscn` through
`pokabow-header-logo-v2.tres`. Its centered, aspect-preserving header was checked
at five phone/desktop sizes. The source PNG and earlier variants remain intact.
