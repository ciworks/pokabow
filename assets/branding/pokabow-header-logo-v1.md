# Pokabow header logo v1

Status: Created 2026-10-05. Transparent raster asset; not integrated into scenes.

Asset: [Pokabow header logo](pokabow-header-logo-v1.png).

## Intended use

A shallow horizontal logo for the in-game header, using the current seven-letter
name **POKABOW**. The gold/ivory wordmark and royal-blue outline retain the
original visual identity. A single spade tile with red, blue, green, and yellow
edge accents carries the poker and edge-matching theme.

The tall crown, paired tiles, ribbons, and lower crest have been removed. Aim
for a visible mark around 150-200 pixels wide; allow sufficient header space
and preserve aspect ratio. The PNG canvas contains transparent padding above
and below the mark, so sizing must account for that padding. It is not a
replacement for accessible text or a gameplay tile template.

## Verification and limitations

- Generated by the built-in image_gen tool using the earlier full-size concept as an edit reference.
- Visually checked the exact POKABOW spelling and simplified composition.
- File is 2172 x 724, 32-bit ARGB; sampled pixels confirm transparent and visible regions.
- Actual device-size readability and integration in a running game remain untested.
- Existing game/website UI strings, repository name, API keys, and archived artwork have not been migrated by this documentation-and-artwork task.

## Final generation prompt

The following is the exact submitted edit prompt. Its reference to the former
spelling identifies the historical input image, not the current game name.

Use case: logo-brand. Edit the supplied logo into a compact mobile in-game header variant and update the brand spelling.
Input image: the previous Polkabow concept is the EDIT TARGET and visual style reference. Preserve its warm ivory/gold lettering, rich royal-blue outline, friendly bold block-serif character, crisp illustrated finish.
CRITICAL exact new wordmark: "POKABOW", seven letters P O K A B O W. Remove the L from the old name. No other words or rank letters.
Recompose as a very wide, shallow, single-line header wordmark, about 5:1 overall logo silhouette. The game places the title in a narrow toolbar above the board, so optimize for approximately 150-200 pixels wide and 30-40 pixels tall. Letters should dominate the entire height and remain readable when reduced. Straight baseline, even letter scale and open counters. Retain a little dimensional gold bevel but substantially simplify fine texture and extrusion.
Remove the two large illustrated playing tiles, large top crown, all fabric ribbons, bottom crest, jewels and all sweeping ornaments. At the left of the wordmark use ONE small bold square ivory tile emblem, with one simple black spade and a clearly segmented frame whose four sides are red, blue, green, yellow. Emblem is aligned to the letters and no taller than the lettering, making a single horizontal lockup. A tiny simple crown may be integrated into the top of the initial P ONLY if it does not increase the overall height or reduce readability; omit it otherwise.
Strong clean navy keyline supports placement on the game's warm wooden and royal blue backgrounds. Keep attractive warm gold/ivory contrast and a tidy silhouette. High-quality final game UI asset with restraint, not an ornate marketing badge.
Genuinely transparent alpha background. Keep the full wide logo centered with modest clear padding. No background panel, no scenery, no black rectangle, no checkerboard baked in, no glow halo. No duplicate variants, no mockup, no tagline, no watermark. Output just one standalone header logo. The only text must be exactly POKABOW.
