# Modern Tabletop avatar rosters

These game-owned default portraits were generated for the Pokabow Modern
Tabletop design direction. They use simplified, friendly 2D cartoon faces,
clean contours, restrained shading, and coordinated teal, sage and peach
backdrops. They are original game artwork; no external portrait or existing
character was used as a source.

- `player-avatar-roster-v1.png`: eight selectable player portraits in a 4 by 2
  atlas. `players/player_01.tres` through `player_08.tres` select the cells.
- `rival-avatar-roster-v1.png`: sixteen AI rival portraits in a 4 by 4 atlas.
  `rivals/rival_01.tres` through `rival_16.tres` select the cells.

The same rival pool is available at every AI difficulty. Difficulty is shown as
text and is not implied by a portrait. Uploaded player photos remain a separate
opt-in profile feature.
