# Tile pot drawer

The [original concept](tile-pot-drawer-concept-v1.png) established the filled
sack and bottom-sheet layout. It pictured tile backs. The owner subsequently
approved face-up remaining tiles with all four edges visible on 2026-10-22.
The [implemented runtime capture](tile-pot-drawer-runtime-540x960.png) shows
that approved revision.

The tile count and tiles come from the live shared source. The grid is sorted
by appearance and does not reveal tile IDs or future draw order. The sheet
shows only the available count, without a generated/distributed breakdown.
Settings remain in the top-right menu.
